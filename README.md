Nappulapeli: Android Companion App

The Android companion app for Nappulapeli, an overengineered autobattling party game built for a trip with friends.

Players use the app to create their characters, purchase upgrades, and manage their loadouts while AI-controlled battles unfold on a shared host screen. The characters fight on their own, leaving players to deal with the consequences of their questionable strategic decisions.

Developed in Kotlin using Android Studio, communicating with a Python/Pygame game host over WebSockets.
